# Design source

Working files for the RefZone visual refresh canvas.

`*.dc.html` are artboards, `canvas.json` lays them out. `refzone-refresh.html`
is the built canvas and is regenerated from these — never edit it by hand.

These are mockups, not shipped code. The values in `System.dc.html` are the
source of truth for the token palette in `app/globals.css`.
